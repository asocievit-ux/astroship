# AstroShip: Bon Voyage

Real-time 3D solar system for iPhone and iPad. The Sun races through the Milky Way at about
243 km/s while the planets orbit it, so every planet traces a helix. Sizes and distances are true
to scale; glowing rings and names make the tiny planets findable, and a tap flies you there.

- `Sources/AstroCore` — Swift package: ephemerides, frames, catalogue, clock, galactic motion
  (no UIKit/SceneKit; reusable for a future visionOS target). `swift test` runs its tests.
- `Sources/App` — SwiftUI + SceneKit iOS app (target `AstroShip`, project generated by XcodeGen from `project.yml`).
- `Resources` — textures, star catalogue, localization (11 languages), icon.
- `tools/build_assets.py` — rebuilds the sky / star / galaxy assets from the original sources.
- `tools/gen_strings.py` — writes `Localizable.strings` from `tools/strings_table.py`.
- `.github/workflows/build.yml` — tests, simulator build and screenshots (manual).
- `.github/workflows/testflight.yml` — signed archive and optional internal TestFlight upload (manual).
